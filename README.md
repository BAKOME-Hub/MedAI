## 🧠 What is MedAI?

**MedAI v8.0 DA VINCI** is the most advanced open-source medical diagnosis AI system ever built. It covers **6 major medical categories** across **12 languages** with **30+ medical sources**, **50+ hospitals worldwide**, and **2500+ lines of pure Rust**.

---

## 🏗️ Architecture

| Module | Description |
|--------|-------------|
| 👶 **Pediatric** | RSV, Neonatal HSV, Rotavirus, Perinatal HIV, Congenital CMV, Measles |
| ❤️ **Cardiovascular** | STEMI, NSTEMI, Stroke, Hypertension, Heart Failure, Arrhythmia |
| 🎗️ **Cancer** | Lung, Breast, Colorectal, Prostate, Leukemia, Lymphoma, Melanoma |
| 🧠 **Neurology** | Alzheimer, Parkinson, MS, Epilepsy, Migraine, ALS, Huntington |
| 🦠 **STIs** | HIV, HBV, HPV, HSV-2, Syphilis, Chlamydia, Gonorrhea, Zika, Ebola |
| 🚨 **Emergency** | Anaphylaxis, Cardiac Arrest, Stroke, Trauma, Overdose, Sepsis |

---

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| 🦀 Rust | Core engine (2500+ lines) |
| 🌐 Axum | HTTP API server |
| 🎥 FFmpeg | Video medical reports |
| 🖥️ Ratatui | Terminal TUI for doctors |
| 📦 TanStack | Diagnosis caching |
| ✅ Vitest | Unit testing |
| 📦 Rollup | Frontend bundling |
| 🔄 Gitoxide | Native Rust versioning |
| 🎨 Svelte | Web dashboard |

## ⚙️ Quick Start

```bash
git clone https://github.com/BAKOME-Hub/MedAI.git
cd MedAI
cargo build --release
cargo run --release
```

Open http://localhost:3002/health
